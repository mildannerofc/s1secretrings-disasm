# Sonic 1 Secret Rings Disassembly

This disassembly is a fork of my own Spindash implementation, including some optimizations and Super Sonic custom sprites.

No content is new here, just only plain Sonic 1 with the Secret Rings moveset that's heavily inspired by MainMemory's Sonic 2 hack.
